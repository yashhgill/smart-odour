About this system

Hardware

  • Microcontroller ESP32 edge device
  • Gas detection MQ-5 (LPG/gas), MQ-6 (butane), MQ-7 ×2 (CO)
  • Ambient DHT11 temperature and humidity
  • Actuator 5V relay to exhaust ventilation

Platform

  • Ingest HTTPS with HMAC-SHA256 request signing
  • Compute Cloudflare Workers, edge deployed
  • Database Cloudflare D1
  • Archive Cloudflare R2, every raw payload retained
  • Alerts Telegram and email, rate limited per zone

Readings are signed at the node, so a measurement cannot be forged by anyone who merely finds the endpoint.
